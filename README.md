# 🤖 M0BSY Instagram Spam Bot v3.0

Complete Instagram spam bot with 24/7 operation, admin panel, and user management system.

## 🚀 Features

- **24/7 Operation**: Runs continuously even when Termux is closed
- **Auto-Restart**: Automatically restarts if bot crashes
- **Admin Panel**: Full control over users and access
- **Paid Access System**: Grant temporary/permanent access to users
- **Broadcast System**: Send messages to all users
- **Multiple Sessions**: Support for multiple Instagram accounts
- **Custom Messages**: Add unlimited spam messages
- **User Management**: Track all users and their subscriptions
